# 디지털 디딤돌

**연성대학교 사회복지경영과 · 성인학습자를 위한 디지털 학습지원 포털**

> 디지털 세상, 이제 어렵지 않게.
> 처음부터 하나씩, 당신의 속도에 맞춰 함께합니다.

교수가 수업에서 따로 나눠 주던 매뉴얼(PDF·PPT·영상)을 한곳에 모아, 성인학습자가 휴대폰이나 컴퓨터로 **한 단계씩 따라 할 수 있게** 만든 웹페이지예요. 2026 교원 바이브코딩 경진대회 출품작이에요.

## 담긴 내용

| 분야 | 안내 수 | 예시 |
| --- | --- | --- |
| 학교 사이트 들어가기 | 2 | 포털 로그인, E-CLASS 이메일 인증 |
| 연성대학교 길찾기 | 6 | 강의실, 입학식장(컨벤션홀), 학과 사무실, 인스퍼레이션 홀, 메이커스페이스실, 무인카페 (영상) |
| 온라인 교육 듣기 | 3 | 법정 의무교육, OCW 국어, 신입생 검사 |
| 컴퓨터 기초 | 8 | 전원, 마우스·키보드, 폴더, 인터넷, 화면 캡처, 이메일 |
| 한글 문서 만들기 | 6 | 글자 모양, 한자, 기호, 표 |
| 스마트폰·AI 활용 | 4 | 캡컷 동영상, ZOOM 접속, QR 코드 |

## 주요 기능

- **한 단계씩 / 한눈에 보기**, 단계마다 실제 화면 사진, 소리로 듣기
- **글자 크기 3단계**, '움직임 줄이기' 버튼 (기기의 동작 줄이기 설정도 따름)
- **해결됐어요 / 아직 안 돼요** 피드백(막힌 단계 번호 + 상황), 안내 제안하기, 안내 요청, 학기별 만족도 조사
- 이름·학번은 받지 않음, 화면 사진 속 개인정보는 흐리게 처리
- 홈 첫 화면 모션: 제목 글자 모션 + 검정 연성대학교 UI가 굴러 지나가며 컬러로 바뀜(성인학습자의 성장)

## 폴더 구성

```
index.html        완성된 페이지 (GitHub Pages가 보여 주는 파일)
img/              단계 사진, 연성대학교 UI
src/
  guides.py       안내 내용(분야·제목·단계·사진·자주 막히는 곳) ← 내용 수정은 주로 여기
  template.html   화면 디자인과 기능, 설정(CONFIG: 연락처·상황 버튼·새 소식 등)
  build.py        guides.py + template.html → index.html 만들기
  manifest*.json  단계 사진 목록
  make_images.py  원본 PDF에서 단계 사진을 잘라내는 도구(원본 PDF는 저장소에 없음)
```

## 고치는 방법

1. 안내 글은 `src/guides.py`, 연락처·첫 화면 버튼·새 소식은 `src/template.html`의 `CONFIG`에서 고쳐요.
2. 저장소 맨 위에서 아래 명령을 실행하면 `index.html`이 새로 만들어져요.
   ```
   python3 src/build.py
   ```
3. 바뀐 파일을 올리면(commit·push) GitHub Pages에 1~2분 뒤 반영돼요.

## 알아 둘 점

- **GitHub Pages에서는 길찾기 유튜브 영상이 화면 안에서 바로 재생**돼요(`CONFIG.youtubeEmbed: "auto"`).
- 피드백·제안·만족도 결과는 claude.ai에 올린 페이지에서는 교수·조교에게 모이지만, **GitHub Pages에서는 각 학생의 기기에만 저장**돼요. 모아 보려면 구글 설문지·스프레드시트 같은 저장 창구를 따로 연결해야 해요.
- AI 도우미는 claude.ai 페이지에서만 나타나요.
